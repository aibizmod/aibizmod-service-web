## FULL CAMPAIGN SETUP CHECKLIST

### Before Launch

#### Google Ads
- [ ] Create 3–5 search ad variants (test headlines)
- [ ] Research and validate keyword list (use Google Keyword Planner)
- [ ] Set up conversion tracking (lead form submission = 1 conversion)
- [ ] Create 2–3 display ad creatives (1200x628px images)
- [ ] Set target CPA ($75–$150 for B2B leads)
- [ ] Choose landing pages (blog post or service page with lead form)
- [ ] Set up UTM parameters (source=google, medium=cpc, campaign=lead-gen)
- [ ] Enable enhanced conversions (if possible in your region)
- [ ] Create separate campaigns by keyword intent (automation, GEO, website redesign)

#### LinkedIn
- [ ] Create 5 sponsored content variants
- [ ] Set up LinkedIn Lead Gen form with follow-up automation
- [ ] Define target audience by job title, industry, seniority
- [ ] Choose link destination (blog post or LinkedIn native form)
- [ ] Set up LinkedIn Pixel on website (for retargeting)
- [ ] Create automated follow-up message in LinkedIn inbox
- [ ] Connect LinkedIn to CRM (auto-sync leads)

#### Meta
- [ ] Create 3 video or image variants (test formats)
- [ ] Upload customer email list (lookalike audience)
- [ ] Set up Facebook Pixel on website (retargeting)
- [ ] Create Meta lead form OR link to external form
- [ ] Define audience exclusions (existing customers, competitors)
- [ ] Create 3 audience segments (lookalike, interest-based, retargeting)
- [ ] Set up automatic lead notifications (email + Slack)
- [ ] Test lead form submission on mobile + desktop

### Tracking & Optimization

- [ ] Set up conversion tracking with UTM parameters for each platform
- [ ] Create shared dashboard (Google Sheets or Looker Studio)
- [ ] Define lead quality criteria (scoring system)
- [ ] Track: Cost per lead, lead quality score, conversion rate to customer
- [ ] Set up automated alerts (high-CPA ads, low-CTR, etc.)
- [ ] Weekly review: Kill underperforming ads, double down on winners
- [ ] Monthly optimization: Improve targeting, refine messaging, adjust budget

### Post-Launch Monitoring

- [ ] Monitor first 48 hours: Are conversions tracking correctly?
- [ ] Check lead quality: Are leads filling out forms genuinely?
- [ ] Validate phone numbers and emails (spam filter test)
- [ ] Test lead delivery to CRM (are leads arriving?)
- [ ] Check competitor ads (what are they running?)

**Important:** Quality matters more than volume. A $150 high-quality lead (likely to buy) is better than a $50 garbage lead (never converts).

### How to Measure Lead Quality

1. **By source:** Which platform converts best?
   - Google = highest quality (search intent)
   - LinkedIn = high quality (targeting)
   - Meta = volume play (convert at lower rate)

2. **By lead score:** Assign points based on job title, company size, industry
   - C-suite = 10 points
   - Manager/Director = 7 points
   - Individual contributor = 3 points
   
3. **By conversion:** Track leads → SQLs → customers
   - 10% of leads should become SQLs (qualified by sales)
   - 20–30% of SQLs should become customers

4. **By cost per customer:** Divide total ad spend by customers acquired
   - Good LTV target: 3x cost per acquisition
   - If CAC = $1,000, customer LTV should be $3,000+

## Optimization Rules (Week 2+)

### Daily Checks
- [ ] Any campaigns paused or showing errors?
- [ ] Cost per lead trending up or down?
- [ ] Any account issues (payment, policy violations)?

### Weekly Optimization
- [ ] Which ad variant has lowest CPC/CPL?
- [ ] Which audience performs best?
- [ ] Which landing page converts highest?
- [ ] Are leads being delivered to CRM correctly?
- [ ] Any budget reallocation needed?

### Bi-Weekly Decisions
- [ ] Pause underperforming ad variants (>$200 CPC with <5% CTR)
- [ ] Increase budget to winners (CPC <$50, CTR >5%)
- [ ] Test new audience segments
- [ ] Refresh creative (same ad for 2+ weeks = fatigue)

### Monthly Analysis
- [ ] What's the actual cost per customer (not just cost per lead)?
- [ ] Which platform has best ROAS (Return on Ad Spend)?
- [ ] Which blog post/landing page drives best conversions?
- [ ] How many leads converted to actual customers?
- [ ] What's the next month's budget based on results?

## Red Flags to Watch For

🚩 **CPA suddenly increases 2–3x**
- Audience fatigue? Increase budget to other audiences
- Quality issues? Check landing page, form, follow-up process
- Seasonality? Check if competitors increased bids

🚩 **High lead volume but low quality**
- Targeting too broad? Narrow by job title, company size
- Landing page unclear? Test clearer CTA
- Form too long? Reduce to 5 fields max

🚩 **Leads not arriving in CRM**
- Check pixel installation
- Verify form submissions are triggering
- Check CRM API connection

🚩 **CTR dropping over time**
- Ad fatigue (same ad for 3+ weeks)
- Audience overlap (same people seeing ads repeatedly)
- Solution: Refresh creative, expand audience, pause lowest performers
