## Workflow notes

- New task/plan docs go into the matching subfolder — never the repo root.
- Completed-work summaries belong in `COMPLETED-TASKS.md` (append, don't rewrite history).
- `scratch/` at the repo root holds one-off scripts (migration/duplicate-fix helpers), not docs.
